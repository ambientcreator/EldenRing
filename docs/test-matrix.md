# Матрица проверок

## Выполненные проверки

| Сценарий | Результат |
| --- | --- |
| Сборка | `node scripts/build.mjs --check` подтвердил совпадение с исходниками. CSS загрузился в Chromium 156 на Linux. |
| Ассеты и фон | 0 отличающихся пикселей после преобразования PNG в WebP. Встроенный WebP совпадает с файлом в `assets/`. Обои, шрифты и орнаменты загрузились без сетевых запросов к внешним сервисам. |
| Настройки фона | Проверены пользовательский URL, X/Y, `contain` и тёмная подложка при `--gr-wallpaper: none`. |
| Селекторы | 153 точных имени классов в CSS темы найдены в 326 бандлах публичной сборки Discord. |
| Размеры окна | 1920 × 1080, 1366 × 768, 2560 × 1440, 3440 × 1440, 760 × 560, 390 × 844 и 320 × 640. В предпросмотре поле ввода осталось в окне, горизонтального скролла не возникло. |
| Навигация и чат | В предпросмотре проверены переход между «Друзьями» и чатом, поиск, реакция, ответ, ввод, переключение участников, меню профиля и модальное окно. |
| Регрессии 0.2.0 | На макете с CSS текущего Discord проверены прозрачность фона «Друзей», цвет карточек профиля, контраст «Добавить в друзья», маска значка с сохранением размеров кнопки, состояния голосовых кнопок и цветная полоса у embed. |
| Голос | В макете проверены переключатели подключения и микрофона. Живой звонок входит в приёмку клиента. |
| Доступность | Проверены фокус, закрытие окон по Escape, латиница и кириллица в Forum и Literata, моноширинный код, Full / Balanced / Lite, снижение движения и увеличение контраста. |
| Контраст | Нижняя оценка контраста вторичного текста на белом участке обоев при настройках Balanced составляет 5,30:1 в чате, 5,03:1 в списке участников, 5,89:1 в каналах и 8,44:1 в строках списка друзей. Это расчёт с учётом затемнения и заливки панелей. |
