Сравнение v0.3.0 и v0.4.0 в Chromium показало иллюстрацию в областях, где ранее рисовались сплошные заливки. В контрольной точке `#channels` RGB вырос с `(17, 17, 17)` до `(76, 69, 61)`, а вокруг плиток с `(0, 0, 0)` до `(51, 46, 42)`. Контрольный пиксель внутри демонстрационного видеокадра дал `(104, 92, 82)` в обеих версиях.

### Прокрутка вложений в 0.7.0

Макет с 60 фотографиями и CSS-модулями Discord прогнали в Chromium 156 на Linux при 1366 × 768 и замедлении процессора 3×. Профиль Balanced в обеих версиях. Для каждого прогона сначала загружались шрифты и изображения, затем подавались 20 событий колеса. В таблице медианы трёх прогонов каждой версии.

| Измерение | 0.6.1 | 0.7.0 |
| --- | ---: | ---: |
| Работа основного потока за прогон | 518 мс | 278 мс |
| Время отрисовки в основном потоке | 79 мс | 41 мс |
| Суммарное время задач растеризации | 317 мс | 325 мс |
| Кадры за секунду покоя | 61 | 0 |
| Сдвиги макета после загрузки вложений | 0 | 0 |

Размеры фото и пройденные 6200 px прокрутки совпали. CSS уменьшился с 2,61 МБ до 0,97 МБ. Эти числа описывают макет. INP и CLS живого сеанса Discord требуют замера в самом клиенте.

### Воспроизведение теста

Тест использует Playwright. Установите браузер Playwright или задайте путь к системному Chromium через `GOLDEN_RUINS_CHROMIUM`.

~~~sh
npm install --no-save --package-lock=false playwright
npx playwright install chromium
node scripts/build.mjs --check
node --test tests/discord-regressions.test.cjs
~~~
