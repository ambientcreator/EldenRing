# Матрица проверок

## Выполненные проверки

| Сценарий | Результат |
| --- | --- |
| Сборка | `node scripts/build.mjs --check` подтвердил совпадение с исходниками. CSS загрузился в Chromium 156 на Linux. |
| Ассеты и фон | 0 отличающихся пикселей после преобразования PNG в WebP. Встроенный WebP совпадает с файлом в `assets/`. Обои, шрифты и орнаменты загрузились без сетевых запросов к внешним сервисам. |
| Настройки фона | Проверены пользовательский URL, X/Y, `contain` и тёмная подложка при `--gr-wallpaper: none`. |
| Селекторы | 124 точных имени классов в CSS темы найдены в 326 бандлах публичной сборки Discord. |
| Размеры окна | 1920 × 1080, 1366 × 768, 2560 × 1440, 3440 × 1440, 760 × 560, 390 × 844 и 320 × 640. В предпросмотре поле ввода осталось в окне, горизонтального скролла не возникло. |
| Навигация и чат | В предпросмотре проверены смена канала, фильтр поиска, реакция, меню, ответ, ввод сообщения как текста, переключение участников и открытие модального окна. |
| Голос | В макете проверены переключатели подключения и микрофона. Живой звонок входит в приёмку клиента. |
| Доступность | Проверены фокус по Tab, закрытие диалога по Escape, Latin и Cyrillic Forum, Full / Balanced / Lite, снижение движения и увеличение контраста. |
| Контраст | Нижняя оценка контраста вторичного текста на белом участке обоев при настройках Balanced составляет 4,90:1 в чате, 4,62:1 в списке участников и 6,15:1 в каналах. Это расчёт для базового текста с учётом затемнения и заливки панелей. |

[Главный экран](preview.jpg) · [Модальное окно](preview-dialog.jpg)

В Chromium при 1366 × 768 добавлены 120 сообщений и 120 участников. Во время синтетической прокрутки медианный интервал между кадрами составил 16,7 мс в каждом профиле. 95-й перцентиль составил 16,7 мс для Balanced и Full, 16,8 мс для Lite. Эти данные описывают макет и не заменяют измерения в Discord.
