Сравнение v0.3.0 и v0.4.0 в Chromium показало иллюстрацию в областях, где ранее рисовались сплошные заливки. В контрольной точке `#channels` RGB вырос с `(17, 17, 17)` до `(76, 69, 61)`, а вокруг плиток с `(0, 0, 0)` до `(51, 46, 42)`. Контрольный пиксель внутри демонстрационного видеокадра дал `(104, 92, 82)` в обеих версиях.

В замере 0.1.0 при 1366 × 768 в предпросмотр добавили 120 сообщений и 120 участников. Во время синтетической прокрутки медианный интервал между кадрами составил 16,7 мс в каждом профиле. 95-й перцентиль составил 16,7 мс для Balanced и Full, 16,8 мс для Lite.

### Воспроизведение теста

Тест использует Playwright. Установите браузер Playwright или задайте путь к системному Chromium через `GOLDEN_RUINS_CHROMIUM`.

~~~sh
npm install --no-save --package-lock=false playwright
npx playwright install chromium
node scripts/build.mjs --check
node --test tests/discord-regressions.test.cjs
~~~
